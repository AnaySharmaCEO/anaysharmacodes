### `01 / EXPERIENCE`

The portfolio was built as an **interactive product rather than a static résumé**.

It combines:

`Smooth animations` · `Interactive navigation` · `Stylized buttons` · `Custom-rendered elements` · `Layered layouts` · `Micro-interactions` · `Responsive design` · `Dark cinematic UI`

The interface uses motion and interaction to progressively reveal information instead of presenting everything at once.

```text
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│   ENTER ──────→ EXPLORE ──────→ DISCOVER ──────→ ACT       │
│                                                              │
│   Motion communicates.                                       │
│   Interaction guides.                                       │
│   Design creates hierarchy.                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### `02 / DESIGN`

The visual system is deliberately minimal, dark and high-contrast.

```text
             DARK
              │
              ▼
          ┌───────┐
          │ FOCUS │
          └───┬───┘
              │
       ┌──────┴──────┐
       ▼             ▼
     MOTION      HIERARCHY
       │             │
       └──────┬──────┘
              ▼
          INTERACTION
              │
              ▼
            ACTION
```

Every element exists for a reason.

**Buttons are interaction points.**
**Animations establish context.**
**Transitions create continuity.**
**Typography establishes hierarchy.**
**Spacing controls attention.**
